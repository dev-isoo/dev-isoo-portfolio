# Dev Isoo Portfolio

Open this folder in VS Code (File > Open Folder) and preview with the Live Server extension.

- `index.html`    page structure and SEO tags
- `css/styles.css` styling (change the gradient in the `--c1/--c2/--c3` variables)
- `js/config.js`   EDIT THIS: domain, contact, socials, stats, projects, services, tech
- `js/main.js`     rendering, interactions, <developer-credit> component

Before launch, search the folder (Ctrl+Shift+F) for `YOUR-DOMAIN.com` and replace it.
Deploy by dragging the folder onto Netlify.
